# 模块 2：层级任务与时间预算

## 本模块范围

- 创建课程、章节、小节、练习和项目实践等层级任务
- 修改任务标题、上级任务、预计学习时间和状态
- 软删除任务及其全部子任务
- `TODO`、`IN_PROGRESS`、`PAUSED`、`BLOCKED`、`DONE` 状态流转
- 80%、100%、150% 时间预算阈值计算
- 层级规则：项目 → 模块 → 任务，任务下还允许再添加一层子任务（子任务不能再继续添加下级）；含子任务的任务作为容器管理，不能直接计时或加入每日计划
- 任务树所有权隔离和 PostgreSQL RLS
- 数据库级同所有者父子约束和防循环触发器
- 任务树与大纲列表两种项目视图，切换选择保存在浏览器本地
- 项目页的成功、失败、校验和本地缓存提醒统一显示中文；任务写入 IndexedDB 前转换为可序列化的普通对象，避免响应式对象触发 `DataCloneError`
- 项目、模块和任务统一使用模态弹窗创建或编辑
- 新建可执行任务时计划用时必须大于 0；小时和分钟同时为 0 时不会保存，弹窗显示红色中文提醒
- 修改可执行任务的计划用时后，同步更新今天及未来日期中引用该任务的每日计划条目；历史日期保持原始快照
- 节点折叠、拖拽调整层级、缩放、进度/优先级/截止日期展示；导图固定在项目面板内部的画布中滚动查看，不随内容撑破页面框架；窗口或面板尺寸变化时自动缩放适配，也可手动缩放与内部滚动查看全部节点
- 独立任务依赖边、带箭头虚线展示及循环依赖校验

任务 API 保留了 `actual_seconds`、`budget_usage_ratio` 和 `budget_level` 字段。
模块 3 已接入 Session 聚合，以上字段现在返回真实学习时长和预算状态。

## 项目页面交互

- 右上角“任务树 / 大纲列表”切换控制同一份任务数据的呈现方式。
- 项目列表的历史计时由数据库按任务聚合后返回，不再把全部历史计时明细加载到应用内存；正在计时的增量仍实时计入父级汇总。
- 项目色彩识别系统：每个项目根据唯一 ID 确定性映射专属主题色，在大纲列表和任务树模式中保持永久一致；下属模块与任务继承该项目主题色，用于左侧竖线、树状连接线和拖拽高亮。
- 任务树整体采用 Apple Liquid Glass 风格，结合 2.5D 扁平化设计，从左向右展示父子关系；导图绘制在项目面板内部的固定高度画布中（面板内滚动，不撑破页面框架），支持折叠、缩放与自动适配；窗口大小变化时画布自动调整缩放比例，使整棵树尽量保留在可视框架内。
- 结构灵活性：项目后面既可以直接添加模块，也可以直接添加可执行任务；任务节点还可以再添加一层子任务（更多菜单中的“新建子任务”），子任务本身不能再添加下级；只有叶子任务可以计时、加入今日计划或被拖成子任务。
- 结构灵活性：项目后面既可以直接添加模块，也可以直接添加可执行任务；不需要强制创建“未分类”或多余子模块。
- 页面背景采用柔和优雅的冷灰、冰蓝与淡紫多层渐变光晕，突出中央任务树的高对比度层次与现代空间感。
- 任务节点采用高对比度半透明 Liquid Glass 材质，具备清晰柔和的边框、背景模糊（`backdrop-filter`）、顶部柔和高光边与立体阴影；所有任务节点严格使用圆角矩形，禁止使用圆形、椭圆、胶囊形或其他几何形状。
- 节点之间使用连续、流畅、无缝闭合的 2px 玻璃质感连接线，单子节点平直直连，多子节点通过圆角分支与垂直主干平滑分叉，杜绝断线与间隙。
- 当任务在今日任务页勾选完成（或达到完成状态）时，即使时间未用完，任务树中对应的任务节点也会实时同步为已完成状态，并在视觉上呈现大号通透的绿色玻璃质感勾选徽标（`✓`）。
- 大纲列表视图同样采用 Liquid Glass 质感（半透明、背景模糊与柔和高光），纵向清晰展示“项目（稳重）→ 模块（轻质）→ 任务（简洁）”层级结构；父任务进入大纲时默认折叠，用户通过节点前的下拉箭头查看或收起子任务，同一父级下的子任务使用一致的缩进、宽度和纵向基线，避免参差错位。
- 点击节点名称或更多菜单中的编辑操作，会打开居中的模态弹窗。新建项目、模块或任务也使用同一弹窗，不再把表单插入到节点下方。

## API

| 方法 | 地址 | 用途 |
|---|---|---|
| GET | `/api/v1/tasks` | 查询当前用户全部有效任务 |
| POST | `/api/v1/tasks` | 创建任务 |
| GET | `/api/v1/tasks/{task_id}` | 查询单个任务 |
| PATCH | `/api/v1/tasks/{task_id}` | 修改任务、父级、预算或状态；计划用时同步到今天及未来的关联每日任务 |
| DELETE | `/api/v1/tasks/{task_id}` | 软删除任务子树 |

所有接口都需要：

```text
Authorization: Bearer <access_token>
```

## 预算规则

```text
实际时间 / 预计时间 < 80%      NORMAL
实际时间 / 预计时间 >= 80%     NEAR_LIMIT
实际时间 / 预计时间 >= 100%    EXHAUSTED
实际时间 / 预计时间 >= 150%    SEVERE
```

历史数据中预计时间为 0 时，预算等级仍为 `NOT_SET`；新建可执行任务已在前端强制设置计划用时。
