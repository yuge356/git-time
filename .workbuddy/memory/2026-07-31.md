## 登录报"无法连接服务器"排查
- 原因：前端 dev 服务器顺延到 5174，而后端 CORS 白名单只有 5173 → 浏览器拦截响应，axios 视为网络错误。
- 处理：backend/.env 的 APP_CORS_ORIGINS 增加 5174（localhost + 127.0.0.1），重启 uvicorn。
- 本地预览启动方式：后端 `cd backend && ./.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000`（SQLite 预览库 timebudget-preview.db，无需 Docker/PostgreSQL）；前端 `cd frontend && ./node_modules/.bin/vite`。改 .env 后必须重启 uvicorn 才生效。
