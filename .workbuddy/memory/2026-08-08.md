# 2026-08-08 工作日志

## 修复"新建任务无法添加到今日任务"

**排查路径**：后端日志 `.local-logs/backend.stdout.log` 显示 `POST /daily-plans/d7bec5f8.../items` 反复 404 与 500；500 堆栈为 `sqlite3.IntegrityError: UNIQUE constraint failed: daily_plan_items.id`；查库确认计划 d7bec5f8 在服务器不存在（本地 IndexedDB 缓存里的幽灵计划 id，无对应待同步操作）。

**根因（两处）**：
1. 后端 `add_daily_plan_item` 的幂等检查只匹配"本计划 + 未删除"的行；软删或异属计划的同 id 行会漏检 → INSERT 主键冲突 500。
2. 前端 `daily-plans.ts addItem` 直连 POST 遇 404/409（计划/任务未同步到服务器）直接回滚并抛错 → 用户看到添加失败。

**修复**：
- 后端：幂等检查改为按 id+owner 全量匹配；命中软删/异属行时复活（重新挂载到当前计划、重置状态、排到最后），不再 500。
- 前端：直连 POST 遇 404/409 时保留乐观项，先 `ensurePlanCreateQueued()` 补录计划创建操作（计划创建按日期幂等 + remapDailyPlan 改写队列），再走有序离线队列投递；其他错误仍回滚报错。
- 前端 `mergeServerPlan`：服务器计划 id 与本地缓存 id 不一致时，合并后删除旧的本地 id 缓存记录，避免同日期两条缓存互相污染。

**验证**：pytest 63 全过；E2E 通过（软删后同 id 重新添加 201 复活、计划按日期幂等返回并 remap、事项随后创建成功）；vue-tsc 通过；后端已重启，前端 5174 正常。

**用户侧自愈**：客户端再次添加时会走 404→队列回放路径自动修复幽灵计划；建议强刷页面。
