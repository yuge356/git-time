# Repository working agreements

## Documentation must accompany feature changes

- Every user-visible behavior or workflow change must update the relevant Markdown documentation in the same change.
- Update `README.md` when the capability summary or user workflow changes.
- Update the matching `docs/module-*.md` file for feature-level behavior and interaction details.
- Update `docs/architecture.md`, `docs/database-schema.md`, `docs/api.md`, or `docs/offline-sync.md` whenever their technical contract changes.
- A feature change is not complete until implementation, verification, and documentation agree.
